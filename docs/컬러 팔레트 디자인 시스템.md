## 컬러 사용 가이드

### Primary `#FF2D55`
- **언제**: 페이지에서 가장 먼저 눈에 띄어야 하는 요소에 사용
- **어떻게**:
  - 메인 CTA 버튼 (`background: var(--color-button-primary)`)
  - 섹션 헤드라인 강조 (`color: var(--color-primary)`)
  - 로고·브랜드 네임 텍스트
  - 내비게이션 활성 탭 표시 (언더라인·점)
- **주의**: 흰색 배경에서만 사용. 핑크 배경 위에는 화이트 텍스트와 조합

### Secondary `#0A1628`
- **언제**: 강렬한 대비가 필요한 전체 배경 섹션에 사용
- **어떻게**:
  - 히어로 섹션·푸터 배경 (`background: var(--color-bg-secondary)`)
  - 다크 테마 카드·모달 배경
  - 텍스트는 반드시 `var(--color-text-white)` 사용
- **주의**: 작은 텍스트는 최소 `#CCCCCC` 이상의 밝기 확보

### Accent `#FF6B8A` / `#FFB3C6`
- **언제**: 장식·보조 요소에 사용. Primary의 보완재
- **어떻게**:
  - 웨이브·블롭 형태의 배경 장식
  - 보조 버튼·태그 배경 (`background: var(--color-accent)`)
  - 카드 테두리·뱃지 아웃라인
- **주의**: Primary와 동시에 과도하게 사용 금지 — 한 섹션에 둘 중 하나만

### Background
- 일반 콘텐츠 → `--color-bg-primary` (`#FFFFFF`)
- 히어로·강조 섹션 → `--color-bg-secondary` (`#0A1628`)
- 서브·카드 배경 → `--color-bg-soft` (`#FFF0F4`)

### Text
- 모든 헤드라인·제목 → `--color-text-primary` (`#222222`)
- 본문·설명 → `--color-text-secondary` (`#666666`)
- 날짜·캡션·비활성 → `--color-text-muted` (`#999999`)
- 다크 배경 위 → `--color-text-white` (`#FFFFFF`)

## 반응형 고려사항

### 다크 모드 대응
```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary:     #0A1628;  /* 라이트 배경 → 딥 네이비로 전환 */
    --color-bg-soft:        #12213A;  /* 서브 배경도 어둡게 */
    --color-text-primary:   #FFFFFF;
    --color-text-secondary: #AAAAAA;
    --color-text-muted:     #666666;
    --color-border:         rgba(255, 45, 85, 0.3); /* 핑크 톤 테두리 유지 */
    /* Primary·Secondary 컬러는 유지 — 브랜드 일관성 */
  }
}
```

## 디자인 특징

이 색상 조합은 **"우주를 향한 에너제틱 테크 브랜드"** 의 정체성을 색으로 구현합니다.

- **딥 네이비 + 핫 핑크의 강렬한 대비** → 글로벌 테크 기업의 진취적 에너지와 도전 정신 표현
- **유기적 코랄 웨이브** → 딱딱한 IT 기업 이미지를 부드럽고 친근하게 완화
- **화이트 콘텐츠 섹션** → 정보 가독성 확보, 핑크 포인트를 더욱 돋보이게
- **전체 톤** → MZ세대를 겨냥한 **에너제틱 테크·라이프스타일 브랜드** 감성
